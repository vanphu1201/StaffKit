# StaffKit v3.0 — Antigravity IDE Pro Engineering Plugin

Bộ đồ nghề 0-token cấp Staff Engineer gắn trực tiếp vào Antigravity IDE: Thiết kế kiến trúc đa phương án, Định vị X-Quang 1-hop Import Graph + Git Co-Change, Khóa hồi quy & chống PASS giả, Pre-Merge PR Review (Blast Radius), Refactor an toàn và Trí nhớ xuyên dự án.

## Thành phần đi kèm
- **MCP Server (`staffkit`, 6 công cụ 0-token):** `load_project_memory`, `locate_context`, `save_project_spec`, `record_lesson`, `verify_and_smoke`, `snapshot_or_undo`.
- **9 Pro Skills kích hoạt theo ngữ cảnh:** `/brainstorm-to-product`, `/refine`, `/decompose`, `/deep-fix`, `/audit-and-evolve`, `/pr-review`, `/refactor-safe`, `/ui-craft`, `/handoff`.
- **Always-On Rules (`rules/AGENTS.md`):** Siêu gọn, tổng overhead luôn bật `< 1,000 token/lượt`.
