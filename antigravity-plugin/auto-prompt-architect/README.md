# Auto-Prompt Architect (Antigravity IDE Plugin)

Biến mọi ý tưởng mơ hồ thành sản phẩm hoàn chỉnh không lỗi **ngay bên trong Antigravity IDE** — kết hợp **100% sức mạnh gốc của Antigravity IDE** (thị giác trực tiếp, Browser QA, hội thoại liền mạch) với **bộ công cụ 0-token của Auto-Prompt Engine**.

## Thành phần đi kèm
- **MCP Server (`auto-prompt-architect`):** 6 công cụ 0-token (`load_project_memory`, `locate_context`, `save_project_spec`, `record_lesson`, `verify_and_smoke`, `snapshot_or_undo`) + 4 công cụ Sprint.
- **Skill `brainstorm-to-product`:** Phỏng vấn đa vòng linh hoạt theo độ phức tạp + Gợi ý chủ động + Cổng chốt đủ ý + Hiến pháp & Hợp đồng dự án.
- **Skill `deep-fix`:** Gỡ lỗi tận gốc 4 bước + Kiểm chứng hành vi thực tế + Tự ghi nhớ bài học vào `.auto-engine/lessons.md`.
- **Always-On Rules (`rules/AGENTS.md`):** Nhắc Antigravity IDE luôn tận dụng trí nhớ dự án và không bao giờ báo PASS giả.
